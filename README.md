# Circle Ball Renderer (v19)

โปรแกรมจำลองฟิสิกส์บอลเด้งในวงกลมพร้อมระบบเสียงสังเคราะห์ตามเมโลดี้ (MIDI / JSON) และเรนเดอร์เป็นคลิปวิดีโอความละเอียดสูง (60 FPS - 240 FPS) สำหรับทำคลิปสั้นแนวตั้ง (TikTok / Shorts / Reels) หรือแนวนอน

## ความต้องการของระบบ (System Requirements)

- **ระบบปฏิบัติการ:** Windows 10 / Windows 11 (64-bit)
- **Python:** เวอร์ชัน 3.10 ขึ้นไป (แนะนำ Python 3.11 หรือ 3.12)
- **FFmpeg:** จำเป็นสำหรับการรวมภาพวิดีโอเข้ากับไฟล์เสียง
- **พื้นที่ว่างบนดิสก์:** อย่างน้อย 1-2 GB (สำหรับ Virtual Environment และไฟล์วิดีโอที่เรนเดอร์)

## วิธีติดตั้งอย่างรวดเร็ว (Quick Start)

หากคุณใช้งานบน Windows และต้องการเริ่มใช้งานทันทีโดยไม่ต้องพิมพ์คำสั่งเอง:

1. ตรวจสอบว่าในเครื่องมี **Python** และได้ติ๊กถูก **"Add python.exe to PATH"** ตอนติดตั้ง
2. ดับเบิลคลิกไฟล์ **`START_HERE.bat`**
3. ระบบจะตรวจสอบ Python, สร้าง `.venv`, ติดตั้งไลบรารีทั้งหมด และทำการ Build เป็นไฟล์ `BallRenderer.exe` ให้อัตโนมัติ
4. เมื่อกระบวนการเสร็จสมบูรณ์ โฟลเดอร์ `dist` จะเปิดขึ้นมา คุณสามารถเปิดใช้งานผ่าน **`dist\BallRenderer.exe`** ได้ทันที

## วิธีติดตั้งแบบ Manual (Developer)

หากต้องการรันโค้ดสดหรือพัฒนาต่อยอด สามารถติดตั้งผ่านคำสั่งใน Command Prompt หรือ PowerShell:

### 1. เข้าสู่โฟลเดอร์โปรเจกต์
```powershell
cd BallRenderer_UI
```

### 2. สร้าง Virtual Environment
```powershell
python -m venv .venv
```

### 3. เปิดใช้งาน (Activate) Virtual Environment
```powershell
.venv\Scripts\activate
```

### 4. อัปเดต pip และติดตั้ง Dependencies
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## การติดตั้งและตั้งค่า FFmpeg

โปรแกรมใช้ **FFmpeg** ในการตัดต่อและรวมไฟล์เสียงเข้ากับวิดีโอ (หากไม่มี FFmpeg โปรแกรมจะไม่สามารถส่งออกวิดีโอพร้อมเสียงได้)

### วิธีติดตั้ง FFmpeg บน Windows:

- **วิธีที่ 1 (ง่ายที่สุดผ่าน Winget):**
  เปิด PowerShell แล้วรันคำสั่ง:
  ```powershell
  winget install Gyan.FFmpeg
  ```
- **วิธีที่ 2 (ดาวน์โหลดไฟล์โดยตรง):**
  1. ดาวน์โหลด FFmpeg Essentials Build จาก [https://www.gyan.dev/ffmpeg/builds/](https://www.gyan.dev/ffmpeg/builds/)
  2. แตกไฟล์ ZIP และนำพาธโฟลเดอร์ `bin` (ที่มีไฟล์ `ffmpeg.exe`) ไปเพิ่มใน System Environment Variables `PATH`
  3. หรือตั้งค่า Environment Variable ชื่อ `FFMPEG_EXE` ชี้ไปยังตำแหน่งไฟล์ `ffmpeg.exe`
  4. (โปรแกรมมีระบบค้นหา `ffmpeg.exe` อัตโนมัติในโฟลเดอร์ Downloads และโฟลเดอร์ของระบบ)

## วิธีการเปิดใช้งาน (How to Run)

### Renderer Studio V2 (PySide6)

เปิดหน้าต่างใหม่ตาม Figma V2 ด้วย:

```powershell
python studio.py
```

หรือดับเบิลคลิก `RUN_STUDIO_V2.bat` เพื่อเปิดโปรแกรมโดยไม่ต้องพิมพ์คำสั่ง

หน้าต่างนี้ใช้ `CircleSimulation` เดียวกับ final renderer สำหรับ Live Preview และใช้ `QProcess` สำหรับ Render MP4 ส่วน `python app.py` ยังคงเปิด UI เดิมเพื่อความเข้ากันได้

### 1. เปิดผ่าน UI โดยตรง (ไม่ต้อง Build)
- ดับเบิลคลิกที่ไฟล์ **`run_ui.bat`**
- หรือรันผ่านคำสั่ง Python:
  ```powershell
  python app.py
  ```

### 2. เปิดผ่านไฟล์ Executable (.exe)
- ดับเบิลคลิกที่ **`dist\BallRenderer.exe`** (หลังจากสั่ง Build แล้ว)

## วิธีการ Build เป็นไฟล์ .EXE

หากต้องการคอมไพล์โปรแกรมใหม่อีกครั้ง:
1. ดับเบิลคลิกที่ **`build_exe.bat`**
2. ระบบจะทำการคอมไพล์ด้วย PyInstaller และคัดลอกโฟลเดอร์ `melodies`, `patterns` และโครงสร้างโฟลเดอร์ที่จำเป็นไปยังโฟลเดอร์ `dist`
3. ไฟล์ที่ได้จะอยู่ที่ `dist\BallRenderer.exe`

## โครงสร้างโปรเจกต์ (Project Structure)

```text
BallRenderer_UI/
│
├── app.py                     # หน้าต่างโปรแกรมหลัก (UI ภาษาไทย ควบคุมการตั้งค่าและพรีวิว)
├── main.py                    # เอนจินจำลองฟิสิกส์ เรนเดอร์ภาพ และสังเคราะห์เสียง
├── requirements.txt           # รายการ Library Python ที่จำเป็น
│
├── engines/                   # ระบบย่อยการคำนวณและฟังก์ชันเสริม
│   └── merge_engine.py        # ระบบผสานลูกบอลและคำนวณฟิสิกส์ Merge
│
├── melodies/                  # โฟลเดอร์เก็บไฟล์โน้ตเพลง/เมโลดี้ (.json, .mid)
│   ├── example_arpeggio.json  # ตัวอย่างไฟล์เมโลดี้แบบ Arpeggio
│   └── river_046.json         # ตัวอย่างไฟล์เมโลดี้
│
├── patterns/                  # โฟลเดอร์เก็บรูปแบบ Pattern การเคลื่อนที่
│
├── assets/
│   └── balls/                 # โฟลเดอร์สำหรับใส่รูปสกินลูกบอล (เช่น 1.webp ถึง 8.webp)
│       └── PUT_IMAGES_HERE.txt # คำแนะนำในการใส่ภาพลูกบอล
│
├── output/                    # โฟลเดอร์เก็บผลลัพธ์วิดีโอ (.mp4) ที่เรนเดอร์เสร็จแล้ว
│
├── START_HERE.bat             # สคริปต์คลิกเดียว ติดตั้งและ Build ครบวงจร
├── run_ui.bat                 # สคริปต์สำหรับเปิดหน้าต่าง UI
├── build_exe.bat              # สคริปต์สำหรับคอมไพล์เป็น BallRenderer.exe
│
└── docs/                      # เอกสารคู่มือและบันทึกการพัฒนา
```

## การใส่รูปภาพลูกบอล (Custom Ball Skins)

คุณสามารถนำรูปภาพสกินลูกบอลของคุณมาใส่ได้:
1. นำไฟล์รูปภาพไปวางที่โฟลเดอร์ `assets\balls\`
2. ตั้งชื่อไฟล์ตามเลเวล เช่น:
   - `1.webp` = เลเวล 1
   - `2.webp` = เลเวล 2
   - ... ไปจนถึง `8.webp`
3. รองรับทั้งไฟล์นามสกุล `.png`, `.jpg`, `.jpeg` และ `.webp`

## ค่าแนะนำสำหรับการเรนเดอร์ (Recommended Settings)

| พารามิเตอร์ | ค่าแนะนำ | คำอธิบาย |
| :--- | :---: | :--- |
| **Resolution** | 1080 × 1920 | ขนาดหน้าจอแนวตั้ง (สำหรับ TikTok, YouTube Shorts, Reels) |
| **FPS** | 240 หรือ 60 | 240 FPS เหมาะสำหรับวิดีโอความลื่นไหลสูงหรือทำสโลว์โมชั่น |
| **Duration** | 20 - 30 | ความยาววิดีโอ (วินาที) |
| **Gravity** | 900 | ค่าแรงโน้มถ่วง ดึงลูกบอลลงสู่พื้น |
| **Initial Speed** | 600 | ความเร็วเริ่มต้นของลูกบอล |
| **Speed Growth** | 1.004 | อัตราการเพิ่มความเร็วในแต่ละครั้งที่เด้ง |
| **Max Speed** | 1750 | เพดานความเร็วสูงสุดของลูกบอล |
| **Ball Growth** | 5 | ขนาดลูกบอลที่ขยายใหญ่ขึ้นในแต่ละครั้งที่เด้ง |
| **Spike Count** | 3 | จำนวนหนามหมุนในวงกลม (สามารถเปิด/ปิดได้) |
| **Rotation Speed** | 0.85 | ความเร็วในการหมุนของหนาม |

## การแก้ปัญหาเบื้องต้น (Troubleshooting)

1. **เปิดโปรแกรมแล้วขึ้นข้อความว่าหา FFmpeg ไม่เจอ:**
   - ติดตั้ง FFmpeg ลงในเครื่อง และตรวจสอบว่าได้เพิ่มใน PATH แล้ว หรือตั้งค่า Environment Variable `FFMPEG_EXE`
2. **รัน `START_HERE.bat` แล้วปิดตัวลงทันที:**
   - ตรวจสอบว่าในเครื่องติดตั้ง Python 3.10+ และตั้งค่าให้ใช้งานคำสั่ง `python` หรือ `py` จากหน้าต่าง Console ได้
3. **ปัญหาชื่อไฟล์ยาวหรือคำสั่งยาวบน Windows (WinError 206):**
   - เวอร์ชันนี้ปรับปรุงกระบวนการผสมเสียงให้ผ่านไฟล์ไทม์ไลน์เดี่ยว (Timeline Audio) จึงไม่เกิดปัญหานี้แล้ว
