วิธีติดตั้ง โปรแกรมบอลเด้งในวงกลม v11

1) แตกไฟล์ ZIP
2) เข้าโฟลเดอร์ BallRenderer_UI
3) ดับเบิลคลิก START_HERE.bat
4) รอระบบติดตั้งและ Build
5) เปิด dist\BallRenderer.exe

วิธีใช้งาน

- ปรับค่าทางซ้ายด้วยสไลเดอร์
- ดูพรีวิวภาพนิ่งทางขวา
- ลูกศรในพรีวิวแสดงมุมเริ่มต้น
- กดปุ่มสีเขียว ▶ เริ่มเรนเดอร์ ด้านล่าง
- ปุ่มเริ่มเรนเดอร์จะอยู่ด้านล่างตลอด ไม่ต้องเลื่อนหา

ค่าแนะนำ
- Width 1080
- Height 1920
- FPS 240
- Duration 20
- Gravity 900
- Initial Speed 600
- Speed Growth 1.004
- Max Speed 1750
- Ball Growth 5
- Arena Scale 1.0
- Spike Count 3
- Rotation Speed 0.85

เสียง
- ใช้เสียงสังเคราะห์ตามจังหวะเด้ง
- เด้ง 1 ครั้ง = เล่นโน้ตถัดไป
- รองรับไฟล์ .mid / .midi / .json
- ไม่มีตัวเลือกเล่น MP3 ต้นฉบับใน UI เวอร์ชันนี้
