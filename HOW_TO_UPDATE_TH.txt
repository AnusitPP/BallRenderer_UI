วิธีอัปเดต

1) เอาไฟล์ app.py และ main.py ไปวางทับของเดิม
2) ถ้าต้องการตัวอย่างแพทเทิร์น ให้นำโฟลเดอร์ patterns ไปวางในโฟลเดอร์โปรแกรม
3) ถ้าจะ Build EXE ใหม่ ให้รัน build_exe.bat

ของใหม่ในเวอร์ชันนี้
- ชนหนามแล้วเลือดลด -> มีเอฟเฟกต์แตก -> กลับไปเกิดใหม่กลางจอ
- ถ้าเลือดหมด จะหายไปถาวร
- เพิ่มระบบ Pattern แบบ B (Timeline JSON)
- เพิ่มปุ่มนำเข้า Pattern JSON ใน UI
- โปรแกรมจะอ่านไฟล์แพทเทิร์นจากโฟลเดอร์ patterns
